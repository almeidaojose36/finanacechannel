| File | Object | Used in |
|---|---|---|
| `lng-carrier.glb` | Membrane-type LNG carrier | Fact 14 |
| `k2-tank.glb` | K2 Black Panther tank | Fact 12 |
| `reactor-apr1400.glb` | APR1400 / Barakah reactor building | Fact 2 |
| `container-crane.glb` | Ship-to-shore container gantry crane | Fact 17 |
| `car-carrier.glb` | Ro-ro car-carrier ship | Fact 16 |
| `ev-battery-pack.glb` | EV battery pack / cell module | Fact 13 |
| `seoul-apartment.glb` | Korean high-rise apartment block | Facts 6, 10 |
| `hbm-gpu-package.glb` | AI accelerator with HBM stacks | Fact 1 |

`Hyundai_Pony_1976.glb` is built procedurally in the 3D-Hardware-GLB-Studio repo.
GitHub's web upload takes files up to 25 MB; larger files (up to 100 MB) need `git push`.
